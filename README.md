### 🚀 Flagship Systems Projects (Built from Scratch)

* **[🔥 MicroTorch](https://github.com/YashrajMiyatra/microtorch)** [![CI](https://github.com/YashrajMiyatra/microtorch/actions/workflows/ci.yml/badge.svg)](https://github.com/YashrajMiyatra/microtorch/actions)  
  A lightweight, zero-dependency Tensor Autograd engine and Neural Network framework built from the ground up with automatic differentiation, modular layers (`Linear`, `Sequential`, activations), and modern optimizers (`SGD`, `Adam`, `AdamW`).

* **[⚡ FlashKV](https://github.com/YashrajMiyatra/FlashKV)** [![FlashKV CI](https://github.com/YashrajMiyatra/FlashKV/actions/workflows/ci.yml/badge.svg)](https://github.com/YashrajMiyatra/FlashKV/actions)  
  A high-performance, Redis-compatible in-memory key-value database featuring an embedded AI vector search engine, multi-key set algebra (`SINTER`, `SUNION`, `SDIFF`), Append-Only File (AOF) persistence, and an interactive real-time web dashboard.

* **[📦 Boxcar](https://github.com/YashrajMiyatra/boxcar)** [![CI](https://github.com/YashrajMiyatra/boxcar/actions/workflows/ci.yml/badge.svg)](https://github.com/YashrajMiyatra/boxcar/actions)  
  A minimalist Linux container engine and Docker Hub OCI image puller inspired by `runc` and Docker, leveraging Linux kernel isolation primitives, namespaces, cgroups, and chroot.

* **[🔍 NovaSearch](https://github.com/YashrajMiyatra/novasearch)** [![CI](https://github.com/YashrajMiyatra/novasearch/actions/workflows/ci.yml/badge.svg)](https://github.com/YashrajMiyatra/novasearch/actions)  
  A production-grade hybrid search engine orchestrating BM25 lexical search, dense vector semantic search, Reciprocal Rank Fusion (RRF), and real-time snippet highlighting.
